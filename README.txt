1) Create a new repository on GitHub.
2) Upload ALL files and folders of this project (keep .github/workflows/android.yml, www/index.html and assets/).
3) Open the Actions tab > Build APK > wait until it turns green.
4) Open the finished run > Artifacts > olomi-game-apk > download > unzip > app-debug.apk.
The app icon is in assets/ (made by make_icon.py).
